How to Fork a GitHub Repository

Fork, clone, branch, commit, push, sync, and create a pull request.

Understand the workflow

Colleague's repository → Fork → Your repository → Clone → Local changes → Push → Pull request
ActionPurpose
ForkCreates your GitHub copy.
CloneDownloads the copy to your computer.
BranchIsolates a change.
CommitRecords it in local Git history.
PushUploads commits to your fork.
Pull requestRequests merging into the original repository.

Steps

  1. Fork the repository

    Sign in to GitHub, open the colleague's repository, select Fork, choose your account as the owner, and select Create fork.

  2. Clone it in Visual Studio Code

    Open the fork, select Code, copy the HTTPS URL, press Ctrl+Shift+P, run Git: Clone, and select a local folder.

  3. Add the original repository 
    git remote add upstream https://github.com/colleague/IoT-Project.git
git remote -v

    origin is your fork; upstream is the colleague's original repository.

  4. Create a branch and make changes 
    git switch -c feature/my-change
# Edit files in VS Code
git add .
git commit -m "Add temperature alert"
git push -u origin feature/my-change
  5. Open a pull request

    On GitHub, open your fork and select Compare & pull request. Verify the base repository, target branch, and your feature branch before submitting.

  6. Keep the fork updated 
    git switch main
git fetch upstream
git merge upstream/main
git push origin main

Troubleshooting

Permission denied: Switch from SSH to HTTPS or configure a GitHub SSH key.
Not a Git repository: Change into the cloned folder or run the clone command again.
Push rejected: Fetch remote changes, merge or rebase, resolve conflicts, and push again.
Changes missing from the original: Pushing updates only the fork. A pull request is needed for the original repository.
